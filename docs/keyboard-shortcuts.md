# Keyboard shortcuts

Every Mathessible command, by window. Where macOS and Windows or Linux differ,
both are given. What each command does is explained in the
[user guide](user-guide.md).

## The equation editor

| Command | macOS | Windows and Linux |
| --- | --- | --- |
| Save the equation and start a new line | `Enter` | `Enter` |
| Save the equation and go back to the document | `Control+=` | `Alt+=` |
| Cancel | `Escape` | `Escape` |
| Linear or professional view | `F2` | `F2` |
| Writing or exploration mode | `F10` | `F10` |

| Cut, copy, paste | `Command+X`, `C`, `V` | `Ctrl+X`, `C`, `V` |

### The linear view

| Command | macOS | Windows and Linux |
| --- | --- | --- |
| Move by character | `Left`, `Right` | `Left`, `Right` |
| Start or end of the equation | `Home`, `End`, `Command+Left`, `Command+Right` | `Home`, `End` |
| Read the source | `Up`, `Down` | `Up`, `Down` |
| Select to the start or end | `Shift+Up`, `Shift+Down` | `Shift+Up`, `Shift+Down` |
| Browse the control word suggestions | `Up`, `Down` while typing one | `Up`, `Down` while typing one |

### The professional view

| Command | macOS | Windows and Linux |
| --- | --- | --- |
| Move by character | `Left`, `Right` | `Left`, `Right` |
| Move by element | `Option+Left`, `Option+Right` | `Ctrl+Left`, `Ctrl+Right` |
| Start or end of the equation | `Home`, `End` | `Home`, `End` |
| Previous or next row (matrix, cases, equation array) | `Up`, `Down` | `Up`, `Down` |
| Select by character or by element | `Shift` with the arrows above | `Shift` with the arrows above |
| Move between matrix cells | `Command+Option` with the arrows | `Ctrl+Alt` with the arrows |
| Read the current cell | `Command+Option+Space` | `Ctrl+Alt+Space` |
| Where typing would go | `Shift+Option+Space` | `Shift+Alt+Space` |
| Read the part the cursor is in (the numerator, the row, ...) | `Option+Space` | `Alt+Space` |
| Where the cursor is ("row 1, column 2; inside numerator") | `Shift+Space` | `Shift+Space` |
| Linear text, or building it again, on a selection | `F2` | `F2` |

In exploration mode (`F10`) nothing changes the equation: `Space` reads
the current element, and without linear navigation `Up` and `Down` move
out of a structure and into it.

## Dialogs

Dialogs use the system's own controls and keys: `Tab` and `Shift+Tab`
between controls, `Enter` for the default button and `Escape` to cancel.
On macOS, `Escape` or `Command+W` closes the Settings window.
