# Changelog

## [0.1.0] - unreleased

The first release: a prototype for trying Mathessible and reporting what reads wrongly.

- Markdown documents with UnicodeMath or LaTeX equations, and `.tex` files.
- An equation editor that speaks, navigates and brailles equations through MathCAT.
- Insert and Format menus: tables with a grid editor, lists, links, images, footnotes, charts and flowcharts.
- Function graphs explored by ear.
- Export to HTML, tagged PDF, Word and BRF; printing.
- Pasting from Word, and importing `.docx` documents through Pandoc (optional).
- Notebooks of pages, kept in a folder or a single `.msnb` file.
- The interface in 15 languages; every translation is a draft by an AI model, not yet reviewed by native speakers.
- Packaged applications for macOS (Apple silicon) and Windows (x64), not signed yet.
